# AI Munimji: Support

Support is best-effort and free. There is no service level.

## Ask a question or report a problem

Open an issue: [link to the repository's Issues page].

Please include:
- your Frappe and ERPNext versions, and whether the site is on Frappe Cloud or your own bench;
- what you did, what you expected, and what happened;
- the exact text of any error message (remove customer names and other private data first).

Please do not post passwords, API keys or customer data in an issue.

## Security problems

Do not open a public issue for a security problem. Write to vivek.vpc1985@gmail.com with "AI Munimji security" in the subject, or use the repository's private vulnerability reporting if it is switched on [check]. You will get an acknowledgement; there is no promised fix time.

## Before you ask

- Read the [User guide](USER_GUIDE.md), in particular "If something does not work".
- Check the known limits in `docs/KNOWN_LIMITATIONS.md`: some things are not part of version 0.1.

## What is covered

Problems with the app itself on ERPNext version 16. Not covered: custom changes to your site, other apps, hosting, and your own ERPNext data.
